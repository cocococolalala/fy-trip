## 安装和使用

### 环境要求
- 微信开发者工具 >= 1.06.0
- Node.js >= 14.0.0
- 小程序基础库 >= 2.19.4

### 安装步骤
1. 克隆项目到本地
```bash
git clone [项目地址]
cd alcohol-detection-miniprogram
```

2. 使用微信开发者工具导入项目
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择项目目录
   - 输入AppID（测试可使用测试号）

3. 预览和调试
   - 点击"编译"按钮
   - 使用"真机调试"测试摄像头功能
   - 扫码在手机端预览

### 配置说明
- `app.json`: 小程序全局配置
- `project.config.json`: 开发工具配置
- `sitemap.json`: 搜索优化配置

## 核心功能实现

### 酒精检测流程
1. **初始化检测**: 摄像头权限申请和设备准备
2. **实时监测**: 30秒检测周期，实时数值更新
3. **结果判断**: 根据阈值判断正常/异常状态
4. **数据保存**: 检测结果和视频自动保存
5. **异常处理**: 异常结果自动提示复检

### 数据存储结构
```javascript
// 检测记录
{
  id: Number,           // 记录ID
  time: String,         // 检测时间
  location: String,     // 检测地点
  value: String,        // 酒精浓度值
  status: String,       // 检测状态 (normal/abnormal)
  temperature: Number,  // 环境温度
  humidity: Number,     // 环境湿度
  duration: Number,     // 检测时长
  videoPath: String,    // 视频路径
  retests: Array       // 复检记录
}
```

### 状态管理
- 使用微信小程序原生的数据绑定
- 本地存储管理用户数据和设置
- 页面间数据传递和状态同步
